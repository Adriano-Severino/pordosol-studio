# 🌅 Criar um Arquivo Por do Sol

A linguagem **Por do Sol** utiliza a extensão `.pr` para arquivos de código-fonte e `.pds` para definições.

### Exemplo Básico:

```pordosol
funcao principal() {
    escreva("Olá, Mundo! Bem-vindo ao Por do Sol Studio 🌅");
}
```

Clique no botão abaixo para criar um novo arquivo `.pr` e começar a desenvolver:

[Criar Novo Arquivo](command:workbench.action.files.newUntitledFile)
