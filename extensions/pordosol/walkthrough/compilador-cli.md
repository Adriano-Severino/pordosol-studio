# 📦 Compilar e Usar a Ferramenta CLI

Você pode compilar arquivos `.pr` para bytecode `.pbc` com otimização máxima ou gerenciar dependências com a ferramenta CLI `pordosol`.

### Comandos e Atalhos:
- **`Ctrl + Shift + B`**: Compilar o arquivo atual para `.pbc`.
- **Terminal Integrado (`Ctrl + \``)**:
  - `pordosol novo meu_projeto`: Cria a estrutura de um novo projeto.
  - `pordosol compilar`: Compila todos os arquivos do projeto.
  - `pordosol executar`: Executa a aplicação.
