# 🚀 Executar e Depurar com F5

O **Por do Sol Studio** possui depurador nativo interativo integrado à IDE:

### Atalhos Oficiais:
- **`F5`**: Iniciar depuração com breakpoints.
- **`Ctrl + F5`**: Executar rapidamente sem depuração.
- **`F9`**: Inserir / remover ponto de interrupção (breakpoint).
- **`F10`**: Passo sobre (Step Over).
- **`F11`**: Passo para dentro (Step Into).
- **`Shift + F5`**: Parar execução.

Abra qualquer arquivo `.pr` e pressione `F5` para ver o código rodando em tempo real!
